## 3. Repair and deploy the existing API

Make these exact routes work on production:

### Posts

GET /api/public/v1/sites/webespokeai/posts

Expected JSON structure:

{
  "items": [],
  "page": 1,
  "pageSize": 10,
  "total": 0,
  "totalPages": 1
}

An empty list is valid when no articles are published.

### Categories

GET /api/public/v1/sites/webespokeai/categories

Expected JSON structure:

{
  "categories": [],
  "tags": []
}

### Sitemap data

GET /api/public/v1/sites/webespokeai/sitemap-data

Expected JSON structure:

{
  "canonical_host": "www.webespokeai.com",
  "urls": []
}

It may contain real verified static or published article URLs.

### Feed

GET /api/public/v1/sites/webespokeai/feed

Expected response:

- HTTP 200
- Content-Type: application/rss+xml
- Valid RSS 2.0 XML

### Single article

GET /api/public/v1/sites/webespokeai/posts/{slug}

Unknown, unpublished, blocked or withdrawn slugs must return:

- HTTP 404
- Content-Type: application/json
- Body:
  {"error":"not_found"}

### Preview

GET /api/public/v1/sites/webespokeai/preview/{itemId}?token=...

Invalid or expired previews must return a controlled 404 without frontend HTML.
