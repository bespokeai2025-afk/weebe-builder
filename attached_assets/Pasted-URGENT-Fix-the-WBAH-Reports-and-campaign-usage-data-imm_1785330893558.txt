URGENT: Fix the WBAH Reports and campaign usage data immediately. This is an implementation task, not an audit or recommendation.

1. Remove provider costs from the client-facing system

Completely remove the following from all normal client views:

- “Actual Provider Cost” cards
- Provider-cost columns
- Retell cost figures
- Dollar amounts
- “Provider cost unavailable”
- Provider reconciliation banners
- Provider call/minute comparisons

Provider costs may remain available only in a restricted WEBEE admin diagnostics area. WBAH and other clients must never see WEBEE’s underlying provider costs.

2. Show only the client usage charge

The only financial metric visible to the client must be:

Client Usage Charge = Minutes Used × £0.36 per minute

Display all charges in GBP.

Calculation rules:

- Sum the exact duration seconds first.
- Divide the total seconds by 60.
- Multiply the unrounded minute total by £0.36.
- Round only the final displayed charge to two decimal places.
- Do not round each individual call before calculating the total.

3. Fix the changing and mismatched totals

The same reporting period currently changes between:

- 467 calls and 511 calls
- 134.15 minutes and 135.42 minutes

This is unacceptable.

For WBAH, make `wbah_calls` the single authoritative source for all client-facing call totals, minutes and campaign reporting.

All cards, charts, campaign tables, performance tables, reports and exports must use one server-side analytics response for the selected period. Do not allow separate page components to independently fetch or calculate conflicting totals.

Investigate and fix:

- Duplicate call rows
- Unstable fallback deduplication keys
- Race conditions between queries
- Stale React Query or server cache data
- Multiple refreshes merging old and new results
- Inconsistent date boundaries
- Joins multiplying calls
- Separate components using different call-status filters
- Sync updates changing rows during the same report request
- Calls being counted once in totals and again during campaign attribution

Deduplicate primarily by the authoritative provider call ID. Where it is missing, use one stable documented fallback key that cannot change between refreshes.

4. Make campaign totals reconcile exactly

Total workspace calls
=
Sum of all campaign calls
+
Unassigned calls

Total workspace minutes
=
Sum of all campaign minutes
+
Unassigned minutes

Client Usage Charge

Total workspace minutes × £0.36

Calls that cannot be reliably assigned must appear under “Unassigned” and must never be dropped or assigned to another campaign just because it uses the same agent.

Calls with no recorded duration may count as calls but must contribute exactly 0 minutes.
