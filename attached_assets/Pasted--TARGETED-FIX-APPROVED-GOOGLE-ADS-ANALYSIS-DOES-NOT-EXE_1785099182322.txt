Possible faults to inspect:

- approval handler only updates approval status
- no execution record is created
- execution exists but remains queued
- dispatcher ignores `gads_analysis`
- task type mismatch such as `gads_analysis` versus another registered capability name
- capability registry has no executor
- worker only runs on a scheduler that is not active
- execution payload is missing campaign ID or workspace ID
- campaign name is present but resolved campaign ID is not passed
- execution is rejected by an approval guard even after approval
- stale frontend query hides real progress
- error is swallowed and task remains In Progress
- task completion is set without report evidence
- duplicate or idempotency guard incorrectly blocks the first execution
